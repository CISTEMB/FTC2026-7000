# Robosharks BIOBUZZ 2026-2027 season

This is the repository for FTC team 7000 Robosharks' BIOBUZZ code. We use a custom library written by one of our team members to use the programming language [Rust](https://rust-lang.org) for our code. You can see the actual code in [TeamCode/team_code_rust/src]. We also automatically generate documentation for our code, which you can see [here](https://cistemb.github.io/FTC2026-7000/team_code_rust).

> [!IMPORTANT]
> You need NDK version 30.0.14904198 to build this.
